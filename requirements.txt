# NOTES
#
# 1. face-recognition / dlib are intentionally NOT used because dlib
#    requires a C++ build toolchain and is very difficult to install on
#    Windows and on machines without cmake. Face recognition instead
#    uses OpenCV's built-in LBPH recognizer (cv2.face), which ships in
#    opencv-contrib-python and works out-of-the-box.
#
# 2. YOLOv8 (ultralytics) will automatically download the base
#    "yolov8n.pt" model on first run. The base COCO model can detect:
#    person, car, motorbike (bike), bus, truck, dog, cat, backpack/
#    handbag (bag), cell phone. It does NOT include helmet, fire,
#    smoke, knife or gun classes - see README.md "Custom Models"
#    section for how to plug in custom-trained weights for those.
#
# 3. GPU/CUDA: if you have an NVIDIA GPU, install a CUDA-enabled build
#    of torch BEFORE installing ultralytics, e.g.:
#      pip install torch --index-url https://download.pytorch.org/whl/cu121
